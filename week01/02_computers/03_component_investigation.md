# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU | The "brain" of the computer. It executes instructions, performs calculations, and coordinates the actions of all other hardware components.|Clock Speed (measured in GHz, e.g., 3.6 GHz) and Core/Thread Count (e.g., 6 Cores, 12 Threads). |
| RAM | High-speed, volatile temporary workspace. It holds data and applications that the CPU is actively using right now so they can be accessed instantly.|Capacity (e.g., 8GB, 16GB) and Generation/Speed (e.g., DDR4 3200MHz, DDR5). |
| Storage | Permanent, non-volatile memory used to save the operating system, programs, and your personal files even when the PC is turned off.| Type (SSD vs. HDD), Capacity (e.g., 512GB, 1TB), and Interface (e.g., NVMe M.2, SATA).|
| Motherboard |The main printed circuit board (PCB) that acts as the central hub, physically connecting and allowing communication between the CPU, RAM, storage, and power supply. |Form Factor (e.g., ATX, Micro-ATX) and Socket Type / Chipset (e.g., LGA1700, AM5). |
| Power Supply |Converts alternating current (AC) from the wall outlet into regulated, low-voltage direct current (DC) power required by the computer's internal components. |Wattage (e.g., 550W, 750W) and Efficiency Rating (e.g., 80 Plus Bronze/Gold). |
| Cooling | Dissipates thermal energy generated by high-power components (primarily the CPU and GPU) to prevent overheating and thermal throttling.|Type (Air cooler vs. Liquid/AIO cooler) and Fan Size (e.g., 120mm, 140mm). |
