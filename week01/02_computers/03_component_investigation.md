# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU | Processes instructions, performs calculations, and coordinates other hardware components.|Clock speed (GHz), Core count, Cache size |
| RAM |Provides temporary, volatile high-speed storage for active data and running programs. |Capacity (GB), Speed (MHz), Generation (DDR4/DDR5) |
| Storage |Permanently stores the operating system, applications, files, and data. | Type (SSD/HDD), Capacity (GB/TB), Read/Write speeds|
| Motherboard | Acts as the central circuit board connecting all components to communicate with each other.|Form factor (ATX/Micro-ATX), Socket type, Chipset |
| Power Supply | Converts AC wall electricity into regulated DC power required by internal components.| Wattage (W), Efficiency rating (80 Plus Certification)|
| Cooling |Dissipates heat generated by components like the CPU to prevent overheating and thermal throttling. |Fan size (mm), Type (Air/Liquid), Noise level (dBA) |
