| Component | Function |
|-----------|----------|
| SoC | integrates the CPU, GPU, and RAM onto a single chip to handle all main processing. |
| GPIO | Pins used to connect and control external hardware, electronics, and sensors. |
| USB | Ports for connecting peripheral hardware like mice, keyboards, and flash drives. |
| HDMI | Outputs digital video and audio signals to an external monitor or display. |
| Power | Input port (USB-C/Micro-USB) that provides electrical power to the board. |
| microSD | Acts as the primary storage drive containing the operating system and files. |
| Network | Ethernet port for establishing a wired local network or internet connection. |
| Wireless | Onboard chip providing built-in Wi-Fi and Bluetooth wireless connectivity. |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**. 
Embedded computers like the Raspberry Pi integrate components into a single board (Single Board Computer) primarily to maximize space and cost efficiency. By combining the CPU, GPU, and RAM onto a single System on Chip (SoC), manufacturers drastically reduce the physical footprint, making the device ideal for compact, portable applications. This integration eliminates individual component packaging and complex modular slots, significantly lowering production costs and consumer prices. Furthermore, shorter electrical paths between integrated components minimize power loss, resulting in excellent energy efficiency and lower heat generation, while the absence of loose wires or socketed hardware increases overall physical reliability.
