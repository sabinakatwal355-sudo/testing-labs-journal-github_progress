# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Computer Hardware refers to the physical, tangible components of a computer system that you can physically touch and see. These computers work together to process data and execute instructions. Internal hardware includes essential items like the Central Processing Unit(CPU), which acts as the brain of the computer, and Random Access Memory(RAM) for temporary data storage, and the motherboard that connects everything. External hardware consists of peripherals like the keyboard, mouse, and monitor, which allow users to interact with the system. Without hardware, software would have no physical platform to run on.

## Explain Software
Write **at least 50 words** explaining what software is.
Software is a collection of intangible instructions, data, and programs that tell a computer's hardware exactly what to do and how to perform specific tasks. Unlike hardware, you cannot physically touch software; it exists purely as digital code written in programming languages. Software is generally split into two main categories: system software, like the Windows or Linux operating system, which manages the background hardware operations, and application software, such as web browsers, video games, or code editors like VS Code, which allows users to complete specific productive or recreational tasks.
