# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware is referred as an physical component of a computer system that we can see and touch, which work together with software to perform computing tasks.If a computer system were a human body, hardware would be the organs, bones, and muscles, while software would be the thoughts, skills, and instructions that tell the body what to do.Hardware is categorized based on its function within the system architectures. and the essential pieces located inside the computer case that do the actual computing and data management are CPU, motherboard,RAM, and storage devices and many more.

## Explain Software
Write **at least 50 words** explaining what software is.
If hardware is the physical body of a computer, software is it's mind. Software consists of the intangible set of instructions, data, programs, and code that tells the physical hardware exactly what to do and how to do it. Without software, a computer would just be an expensive paperweight i.e. a collection of plastic, metal, and silicon with no way to function.Software are of two types and they are system software and application software.
